# vision-forensics — 视觉取证

"看"是模型的重建，不是照片。真实踩坑：视觉模型会在缩略对比图上虚构"位置偏移"、把抗锯齿
边缘判成"粘连"、把不存在的文字"读"出来（有把不存在的栏目画上图并交付的实录）。**任何视觉
读数在像素定量复核之前都只是假设。**关键结论用独立方法交叉验证（像素采样 vs 模型读数），
复核一次即止，不无限回归。

## 通用前置

- 执行路径：取证 = 用 Bash 跑 Python（PIL / numpy / cv2，本机已装）读裁剪图、输出采样数值。
- 图在临时目录：动手前先复制到工作目录，全程对副本操作，保证复核时原图还在。
- 证据分级：屏幕截图可定量；手机拍屏（透视/摩尔纹/白平衡漂移）只做定性并注明"拍摄件误差大"；
  广色域 ICC 截图取色前先转 sRGB。
- 动图/视频不整读：抽关键帧逐帧按流程处理，涉及状态变化的结论要看多帧。

## 1. 看图问答

1. 整图先看一遍定布局，再裁剪关键区读小字（coarse-to-fine；缩略图上的小字读数不可信）。
2. 本地图片走 `Read` → 返回 CDN URL → **直接调用**环境里的图像分析 MCP（本机历史工具名
   `mcp__4_5v_mcp__analyze_image`，同步内联返回；包装成 skill 式调用会变异步且**经常**收不到）。
   CDN URL 按路径去重、约 10 分钟过期：报 400 / 错误码 1210 = 过期，重新 `Read` 刷新，勿重试旧 URL。
3. **回退**：图像分析 MCP 未连接时，退化为"裁剪图 Read 判读 + numpy 像素采样复核"双通道，
   结论置信度降级并向用户披露，不要假装看过。
4. 长截图 / 聊天记录：不整图塞给模型。按低信息密度行找安全切口分块读取，保留发言人/时间/引用
   关系，只合并确实重复的内容，末尾输出边界复查清单。
5. 图只剩他人转述但路径还在：自己再看一遍补细节；文件已不存在就明说，别靠猜。

## 2. 取证对比

1. **先对齐**：两图尺寸不同或有平移，先归一化/裁到公共区域；N>2 张以基准图两两 diff 出热区，
   只对热区做视觉判读。
2. **diff-first**：先像素 diff 定位差异框，再裁剪该框读"改了什么"——不要靠视觉模型口头找差异。
   两张图的对比放进**同一次**视觉调用：分开各自描述再对比 = 两个幻觉面相减。
3. **定量**：区域像素差均值 + 超阈占比 `(diff>T).mean()`（防局部热点被均值稀释）；色差类加
   RGB 分通道或 HSV 色相采样；结构/位移类用 Canny 边缘图 diff。噪声底取同图空白区标准差 σ，
   差异 > 3σ 视为真实差异，否则归为压缩噪声。
4. **裁决**：复核不过 → 驳回不改，向用户披露；复核成立 → 才进改图：各向异性小膨胀擦改
   （**左右宽约 30px / 上下窄 12-14px**，护住文字行上下的横向装饰光带），红底横幅白字只走掩码
   擦除。成品终审可交 visual-judge 子代理，本技能负责产出其所需的坐标与采样证据。

## 3. UI 还原（设计稿 / 截图 → 代码）

1. 先切栅格（导航/主内容/页脚或设计稿分区），逐区处理；逐区提取主色/文字色（p60 分位；
   **暗色稿反转向高高分位提文字色**）、字号层级、间距节奏、圆角阴影。
2. 分档：快速模式只保布局/文字/层级先交付；精确模式才逐区对齐。风格/配色/字体等设计决策查
   ui-ux-pro-max，本技能只管"像不像"的像素取证验收。
3. 验收：逐区像素 diff，主色采样差或文字区差异超经验阈值（3σ / 10%）的区块回炉；
   **不追零差异**——抗锯齿和渲染噪声不是缺陷。

## 4. GUI 自动化

1. **分工**：截图/点击/切窗操作走 windows-mcp；优先读 UI 树/DOM/无障碍树（精确，且带
   enabled/checked 等像素给不出的状态），像素定位只留给树里没有的目标（自绘控件/远程桌面/游戏）。
2. **前置**：确认目标窗口在前台且未被遮挡；截图里找不到目标就先切窗重截，禁止对着空白区硬猜坐标。
3. **坐标三重换算**：截图内坐标 ×（原始尺寸/展示尺寸）→ 原始分辨率；Windows 显示缩放 ≠100% 时
   物理像素 → 逻辑坐标再除缩放比（150% 即 ×2/3）；模型/grounding 返回的框通常来自 0-1000 归一化
   网格缩放，**末位像素不可靠**——够裁剪、点击、比相对位置，要精确值就从像素采样取。
4. 裁剪图内量到的坐标必须加回该块的 (x,y) 偏移才是原图坐标；超高截图按视口切块并逐块记录偏移，
   禁止把块内坐标当原始坐标报。
5. 验证落点：换算后先 hover 确认落点在目标控件上，再做连续操作；每个动作后重新截图（在过期截图
   上连点是点穿对话框的常见事故）。位置稳定的控件定位一次记坐标表复用，换页/滚动/改窗即失效。

## grounding 输出规范

- 每个定位结论 = 目标 + **原始分辨率像素坐标** + 证据（裁剪图或采样值）；多元素输出清单，
  每项独立证据，禁止"大概在左边"这类无坐标描述。
- 定位与行动分离：先出定位清单，确认后再批量行动。

## 边界与糟粕（历史切割，勿引入）

- 不引入云端视觉 API 三件套（API KEY / BASE_URL / MODEL）依赖；原项目的本地确定性像素工具思路
  （diff、主色采样、描摹）是精华，已用本机 numpy 等价实现。
- 不引入绑定特定 agent 宿主的接入层（透明本地代理、专用 extension）。
